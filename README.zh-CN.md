# AwakeLid：Awake 合盖唤醒扩展

简体中文 · [English](README.md)

**在 PowerToys Awake 原托盘菜单中添加合盖唤醒选项，随唤醒会话临时生效，到期恢复原设置。**

无需修改或重新构建 PowerToys，无需安装 Windhawk。本项目为独立社区扩展，与 Microsoft 无隶属或背书关系。当前程序界面为中文；英文 README 是使用介绍，未实现英文界面。

## 使用要求

- Windows x64，安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)。
- 由 PowerToys 主程序启动、管理的 Awake；不支持独立命令行实例。
- 已验证版本：**PowerToys Awake 0.101.2362.0**。其他版本可能需要适配。
- 当前构建 **0.1.2**，自动检查覆盖文件占用、策略恢复及隐藏菜单。用户于 2026-11-02 确认 **0.1.1** 的真人合盖验收完成并通过；这项用户反馈与新版的自动验证分别记录。

## 开始使用

1. 将 `AwakeLid-v0.1.2-win-x64.zip` 解压到可写的独立目录，保留整个目录。
2. 在 PowerToys 中启用 Awake，双击 `AwakeLid.exe`。外挂与 PowerToys 使用相同权限级别。
3. 右键 Awake 原咖啡杯图标，打开“合盖保持唤醒”。
4. 开始 Awake 唤醒会话后，在“跟随 Awake”下选择插电、电池或同时选择两项。

```text
合盖保持唤醒 >
    跟随 Awake
        □ 接通电源时
        □ 使用电池时
    ------------------
    ✓ 跟随系统设置
```

Awake 关闭时，两项置灰且不能操作；保留已保存偏好。“跟随系统设置”始终可选，清除两项选择并恢复仍由外挂管理的临时设置。首次启动默认跟随系统，单独启动助手不修改电源策略。

## 联动规则

- 对每个电源计划的插电、电池合盖动作分别保存原值；唤醒期间临时设为“不执行任何操作”。
- 计时结束、手动关闭 Awake 或 Awake 进程退出后恢复。延长会话保留最初备份，切换计划先恢复旧计划。
- 发现用户手动修改后，保留最新值，暂停对应供电模式本次会话的联动。约每 0.5 秒检查一次，不能识别采样之间改走又改回同值的操作。
- 修改前先可靠写入磁盘恢复记录；助手意外退出时，Hook 可启动一次恢复进程。下次启动也会检查遗留记录。
- 状态和日志文件仅用于诊断。`status.json` 或日志被占用时，单独显示诊断提示，五秒后自动重试，不暂停合盖联动、不阻止到期恢复；相同状态不重复写盘。日志最多缓冲 128 条，超出时明确提示丢弃数量。恢复记录 `state.json` 仍必须在修改电源设置前成功保存。
- 只写合盖动作，不修改睡眠超时、休眠开关、唤醒定时器；不强制睡眠。保持唤醒由 Awake 提供。

恢复合盖设置不保证已经合盖的电脑立即睡眠，后续由 Windows 决定。两个进程同时退出、断电或消息线程卡死时，无法保证即时恢复；恢复成功前保留 `data/state.json`。错误可在状态与日志查看，通知可能受勿扰设置影响。未知 Awake 版本先验证菜单再接管设置，不能保证识别所有未来兼容问题。

## 自启动、停止和卸载

| 入口 | 功能 |
| --- | --- |
| `AwakeLid.exe` | 后台启动，不新增常驻托盘图标 |
| `Status.cmd` | 查看状态 |
| `InstallStartup.cmd` | 主动设置当前用户登录启动快捷方式 |
| `Stop.cmd` | 恢复、移除 Hook 并停止助手 |
| `Uninstall.cmd` | 恢复、退出、核实 DLL 释放，将启动项和程序目录送入回收站 |

**默认不注册开机自启动。** 支持 OneDrive 云占位目录及经父目录联接访问的安装。安装目录本身是联接、符号链接或未知重解析类型时拒绝回收。卸载只允许进入回收站，回调拒绝永久删除；恢复、核实或回收失败就停止并保留剩余文件，不强制结束 PowerToys。卸载会回收整个独立程序目录，包括用户另外放入的文件，因此不要与其他资料混放。

原目录升级：先运行旧目录的 `Stop.cmd`，确认恢复成功、助手退出；再将新运行包目录内的文件覆盖到原安装目录，保留 `data/`，然后启动 `AwakeLid.exe`。保留原目录可沿用已有启动快捷方式。停止会清除跟随选项，Awake 开启后重新勾选即可。不要覆盖运行中的程序，也不要丢弃尚未恢复的记录。

## 从源码构建

在源码仓库目录中（非运行包目录），Windows x64 安装 .NET SDK **8.0.426**，在 PowerShell 7 中运行：

```powershell
.\build.ps1
.\pack.ps1
```

构建脚本从 Zig 官网下载固定版本 **0.14.1**，核验 SHA-256 后放入 `artifacts/toolchain`；已有工具链可传入 `-ZigPath C:\path\to\zig.exe`。只构建本外挂，不需要 PowerToys 源码。发布包依赖已有 .NET Desktop Runtime。

测试使用隐藏模拟窗口和内存电源设置，可选的实际电源探针只读。回收测试只处理专用副本。CI 使用 `-Ci`，跳过依赖真实设备的读取和 Shell 回收操作，保留隐藏 Hook 测试与标签分类；不代表硬件验收。

发布产物位于 `dist/`，运行包与源码包分开提供；运行包不包含个人恢复记录、日志、测试程序和编译器缓存。参阅[发布流程](docs/RELEASING.md)、[验证概览](docs/VALIDATION.md)、[中文验证记录](docs/VALIDATION.zh-CN.md)和[第三方声明](THIRD_PARTY_NOTICES.md)。

## 实现与许可

`src/AwakeLid/` 为后台助手和电源恢复逻辑；`src/NativeHook/` 为原生消息 Hook；`tests/` 为测试。Hook 仅针对 Awake 窗口线程，不修改 PowerToys 文件，不安装服务或驱动，不监听键鼠。项目采用 MIT 许可，原生运行库声明另附。
