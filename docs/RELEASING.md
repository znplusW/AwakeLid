# Release preparation / 发布准备

## Local build

Run PowerShell 7 on Windows x64 with .NET SDK 8.0.426:

```powershell
.\build.ps1 -ZigPath C:\path\to\zig.exe
.\pack.ps1
```

Omit `-ZigPath` to download and checksum-verify the pinned official Zig archive. `build.ps1 -Ci` uses the CI-safe test subset. The workflow builds and uploads run artifacts only; it does not create a GitHub Release or push a tag.

The runtime ZIP is framework-dependent. It includes the application, native Hook, scripts, bilingual documentation, licensing and file checksums. It excludes source, data, logs, test fixtures and build caches. Never package a directory copied from an active installation.

## Public source and author metadata

Git commits retain author names and email addresses regardless of whether user.name/user.email were configured locally or globally. A direct push publishes that history. Before a public first push, review authorship and use the intended public identity; if necessary create a separate clean repository or explicitly rewrite unpublished history. A source ZIP generated by `git archive` excludes `.git`, local configuration and commit author records.

Git 提交中的作者信息会随提交历史推送。仅在本地配置身份不代表其不会公开；公开前请核对作者身份。源码 ZIP 不包含 `.git`、本地配置或提交作者记录。不要把包含私人身份的本地 Git 仓库整体压缩后当公开源码上传。

## Release description: v0.1.2

AwakeLid adds session-linked lid-close controls to PowerToys Awake's existing tray menu without rebuilding PowerToys. AC and battery choices are independent, disabled while Awake is off, and restored at session end. Detected manual system changes take priority. Version 0.1.2 prevents locked status/log files from suspending lid control, retries diagnostics automatically, and keeps recovery-journal failures strict. It retains OneDrive-aware, recycle-only uninstall.

AwakeLid 在 Awake 原托盘菜单增加合盖联动控制，无需重构建 PowerToys。插电与电池独立可选，Awake 关闭时置灰，会话结束恢复原值，检测到的手动修改优先。0.1.2 修复状态或日志文件被占用后误暂停联动的问题，自动重试诊断写入，同时保留恢复记录的严格检查；继续支持 OneDrive 云目录及仅回收站卸载。

Requirements: Windows x64, .NET 8 Desktop Runtime, PowerToys-managed Awake. Validated Awake version: 0.101.2362.0. Current UI is Chinese. The user reported physical lid-close acceptance passed on 0.1.1 on 2026-11-02; 0.1.2 verification is automated and does not claim a repeated physical test. Binaries are unsigned. See README limitations and validation records.

Assets: runtime ZIP, public source ZIP, SHA-256 checksums. Publish v0.1.2 as a normal release (not a prerelease), with a public Git identity as described above.
