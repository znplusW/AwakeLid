## 实际边界

- Windows 的通知开关、勿扰模式可能隐藏提示，日志和状态仍可查看。
- Hook 无法对所有未来版本保证兼容；当前有进程、窗口、模块握手、菜单写入及设置读写错误检测。未验证新版先提示并等待菜单验证。
- 助手与 Awake 同时被强制结束、系统断电或消息线程挂起时，实时恢复不能保证；磁盘恢复记录用于下一次启动或 Stop.cmd 的补偿恢复。
- 恢复合盖动作不等于立即执行睡眠；已有合盖状态的后续行为由 Windows 决定。
